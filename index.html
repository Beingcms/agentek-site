Control, in plain words

Four questions your risk team will ask. You will have the answers.

Who can send which data to which model?

Rules by role and by type of data. For example, customer records go only to models inside your cloud.

Where does each model run?

In your cloud, with a UK or EU provider, or through a frontier API, chosen step by step.

What does it cost?

Cost per 1,000 cases for each model, measured in testing and tracked once it runs.

How do you know when a model fails or changes?

We re-run your locked test set whenever a model or its version changes, and each approved version carries a signed passport.

Routing tools pick a model for each request. We give you the tested rules and the evidence behind them, across the whole workflow.

In a pilot: your own sign-in, four roles, an audit trail, signed jobs, a locked test set, and containers that run in your cloud.

How we test: ModelFit

Every option sits the same exam.

ModelFit is the tool we use to test each option on cases it has never seen. The test set is locked before any model is tried, and each approved model gets a signed passport your risk team can check.
